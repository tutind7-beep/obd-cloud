# OBD-Диагност — облачный бэкенд (Фаза 1)

Облачная версия приложения: аккаунты, сохранение автомобилей, история
диагностик и советы ИИ. Это серверная часть для будущего мобильного
приложения (Фаза 2).

## Что уже умеет

- Регистрация и вход (`POST /api/register`, `POST /api/login`)
- Профиль и автомобили (`GET /api/me`, `POST /api/vehicles`)
- Советы ИИ по кодам и параметрам (`POST /api/advice`)
- Диагностика по симптомам (`POST /api/symptoms`)
- История диагностик (`GET /api/history`)
- Демо-данные параметров (`GET /api/live`)
- Расшифровка VIN (`GET /api/vin/<vin>`)
- Веб-интерфейс на главной странице

## Запуск локально

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python app.py
```

Откройте http://127.0.0.1:8000/

## Запуск на Render

1. Создайте бесплатный аккаунт на render.com
2. New → Web Service → подключите эту папку (GitHub) или загрузите файлы
3. Render сам прочитает `render.yaml` и `Procfile`
4. В настройках сервиса укажите переменную `DEEPSEEK_API_KEY`

## Переменные окружения

См. `.env.example`.

## Важно: сохранность данных

База — файл SQLite (`obd.db`) внутри контейнера Render. У бесплатного тарифа
файловая система **временная**: при перезапуске сервиса (в том числе после
сна) контейнер создаётся заново, и файл исчезает. Аккаунты и история
пропадают.

Проверить текущий режим можно по адресу `/api/health`:

```json
{"ok": true, "storage": "temporary", "storage_note": "..."}
```

Что делать (любой из вариантов):

1. **Постоянный диск Render** (платный тариф). В дашборде: сервис → Disks →
   Add Disk, точка монтирования `/var/data`. Затем добавьте переменную
   `OBD_DB_FILE=/var/data/obd.db`. Код уже читает эту переменную — после
   изменения `/api/health` покажет `"storage": "persistent"`.
2. **Внешняя база** (PostgreSQL на Supabase/Neon, бесплатные тарифы) —
   потребует переписать `database.py` с `sqlite3` на драйвер PostgreSQL.

## Примечание

- Реальные данные с OBD-адаптера присылает мобильное приложение
  (поля `codes` и `live` в `/api/advice`). Без них включается демо-режим.
- Бесплатный инстанс Render засыпает через ~15 минут простоя. Первый запрос
  после сна идёт 20–30 секунд — приложение это учитывает и будит сервер
  запросом `/api/health`.
